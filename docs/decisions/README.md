# 결정 목록
- 명세를 쓰다 불명확·중복·충돌하는 요구사항이 나오면 여기 **한 파일에** 모은다 (API·DB 명세 모두). 파일명 `<기능명>.md`
- `추천` 칸에 AI 추천값을 적는다. 명세에는 추천값을 먼저 반영해 둔다.
- 사람은 `결정` 칸만 채운다:
  - `추천대로` → 추천값 확정
  - 선택지 중 하나 또는 원하는 내용을 문장으로 → 그대로 반영
  - `질문: <내용>` → 명세는 바꾸지 않고 PR 코멘트로 답한다
  - 비워 둠 → 바꾸지 않는다
- 사람이 정하고 싶은 것이 더 있으면 줄을 추가한다 (`D<다음 번호>`).
- PR 코멘트로 결정해도 된다: `D<번호>: <결정>` 형식으로 한 줄에 하나씩.
- 반영된 줄은 `결정 완료` 로 옮긴다.

```markdown
## 결정할 것
| 번호 | 무엇을 정할까요? | 선택지 | 추천 | 결정 |
|---|---|---|---|---|
| D1 | 닉네임 중복을 허용하나? | 허용 / 불가 | 허용 | |

## 결정 완료
| 번호 | 결정 | 반영 커밋 |
|---|---|---|
```
