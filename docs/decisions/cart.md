# 장바구니 결정 목록

요구사항 문서가 없어 아래 항목은 추천값을 명세에 먼저 반영했다. 번호는 이 파일 안에서만 쓴다. `docs/db/schema.md` 와 명세 본문에서는 이 파일의 번호를 `결정 필요 D<번호>` 로 적고, 다른 목록의 번호는 `member D5`, `product D15` 처럼 도메인 이름을 붙인다.

이미 다른 결정 목록에 있는 쟁점은 다시 묻지 않고 그 번호를 따른다.

- 인증·권한(로그인 필요 여부): `docs/decisions/member.md` D3, `docs/decisions/product.md` D15
- 400 메시지 구분: `docs/decisions/product.md` D19, `docs/decisions/member.md` D6
- 회원이 없을 때: `docs/decisions/member.md` D5 (404 "회원을 찾을 수 없습니다.")
- 삭제 방식(물리 삭제): `docs/decisions/product.md` D16

## 결정할 것
| 번호 | 무엇을 정할까요? | 선택지 | 추천 | 결정 |
|---|---|---|---|---|
| D1 | "장바구니 API" 에 어떤 API 를 포함하나? (요청에 범위가 없음. API 마다 명세 파일이 하나씩 필요) | 담기+조회+수량 변경+항목 삭제 / 위에 장바구니 비우기(전체 삭제) 추가 / 담기+조회만 / 직접 지정 | 담기(`POST`), 조회(`GET`), 수량 변경(`PATCH`), 항목 삭제(`DELETE`) 4개. 장바구니로 필요한 최소 동작이며 주문 연결·전체 비우기는 요구사항에 없어 제외 | |
| D2 | 장바구니 소유자를 어떻게 식별하나? (로그인·인증 명세가 아직 없음) | URL 에 memberId (`/api/carts/{memberId}/items`) / 인증 정보에서 꺼냄 (URL 에 없음, 인증 방식 결정 필요) / 쿼리 파라미터 memberId | URL 에 memberId. 인증 요구사항이 없어 요청만으로 소유자를 알 수 있음. 인증이 정해지면 URL 이 바뀔 수 있음 | |
| D3 | 이미 담긴 상품을 다시 담으면? | 기존 항목에 수량 합산 / 409 로 거부 / 별도 항목으로 추가 | 기존 항목에 수량 합산 (회원+상품당 항목 1개, DB 에 `member_id, product_id` 유일 제약). 합산한 경우에도 응답은 `201` 과 합산된 항목 | |
| D4 | 수량 범위는? | 1 이상 정수(상한 없음) / 1 이상 N 이하(N 직접 지정) / 0 허용(0 이면 삭제) | 1 이상 정수(상한 없음). 수량 0 은 항목 삭제 API 로 처리 | |
| D5 | 담기·수량 변경 시 재고(`product.stock`)를 검증하나? | 검증 안 함 / 재고 초과 시 400 또는 409 | 검증 안 함 (재고 확인은 주문 시점의 일이고 주문 요구사항이 없음) | |
| D6 | 장바구니에 담긴 상품이 삭제되면? (상품 삭제는 물리 삭제, product D16 추천) | 항목도 함께 삭제 (`ON DELETE CASCADE`) / 담긴 상품은 삭제 거부 / 상품 논리 삭제로 바꾸고 항목은 "삭제된 상품" 으로 표시 | 항목도 함께 삭제. 상품 삭제 API(`docs/api/product/delete.md`)는 이번 작업에서 바꾸지 않았으며, 결정되면 그 명세에 영향이 있는지 따로 확인해야 함 | |
| D7 | 항목 응답에 상품 정보를 얼마나 담나? | id, productId, productName, price, quantity, createdAt, updatedAt / productId 만 (상품 정보는 클라이언트가 따로 조회) / 위에 stock·합계금액 추가 | id, productId, productName, price, quantity, createdAt, updatedAt. price 는 담은 시점이 아니라 조회 시점의 상품 현재 가격(별도 저장 안 함). 합계 금액은 응답에 넣지 않음 | |
| D8 | 장바구니 조회에 페이징·정렬을 쓰나? | 전체 반환(담은 순) / product D18 처럼 page·size·sort | 전체 반환, id 오름차순(담은 순). 응답은 `items` 배열 | |
| D9 | 다른 회원의 항목 `cartItemId` 로 수량 변경·삭제를 요청하면? | 404 "장바구니 항목을 찾을 수 없습니다." (없는 항목과 같음) / 403 | 404 "장바구니 항목을 찾을 수 없습니다." (항목 존재 여부를 노출하지 않음, 인증이 없는 현재 별도 권한 정책을 만들지 않음) | |
